# Official SOLIDWORKS API for SWCLI coverage gaps

Use the official API help for the SOLIDWORKS version running in the target host. Check the interface, parameters, return values and side effects before calling it. Report SWCLI and native API results separately.

For MacSW, native SOLIDWORKS COM runs inside Wine. Use the existing bottle's Windows Python and pywin32 with the same MacSW Wine runtime. The App's `Contents/Resources/SWCLI/bin/swcli-daemon-utils` shows how to set `WINEPREFIX`, `WINELOADER` and `WINESERVER`, and how to launch Windows Python through the bundled `wine_runtime.py launch` guard. For a probe use `C:\MacSW\Python311\python.exe`; translate any host script path with the bundled `Contents/Resources/SWCLI/bin/swcli-path` using that bottle's `WINEPREFIX`. Keep any probe and output in temporary files outside the App.

Initialize COM on the calling thread. Attach only to the existing instance using `win32com.client.GetActiveObject("SldWorks.Application")`, and compare `GetProcessID` to the daemon's Windows `host.process_id` for the same bottle. Resolve the intended open document and confirm its full path, type and relevant configuration before making the query. If the instance or document cannot be verified, stop and report the blocker. Do not launch a second SOLIDWORKS or run a direct COM script concurrently with a CAD operation.

- **Motion studies**: Use `IModelDocExtension.GetMotionStudyManager` then `IMotionStudyManager.GetMotionStudyNames` or `GetMotionStudyCount`. The list can include Simulation studies. Use `IMotionStudy.StudyType` when the distinction matters. [SOLIDWORKS Motion Study API](https://help.solidworks.com/2025/english/api/swmotionstudyapi/SolidWorks.Interop.swmotionstudy~SolidWorks.Interop.swmotionstudy.IMotionStudyManager.html)
- **Exploded views**: Use `IAssemblyDoc.GetExplodedViewNames2` for the requested configuration. Motion study tabs and a top-level feature list do not establish whether that configuration has exploded views. [SOLIDWORKS Assembly API](https://help.solidworks.com/2021/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IAssemblyDoc~GetExplodedViewNames2.html)

For an inspection request, use read-only getters. Keep activation, playback, rebuild, editing, saving and exports within the user's requested scope. Before any direct mutation, verify the target and ensure exclusive access for the operation because SWCLI leases do not coordinate an independent COM client. If the required API fails on this installation, report the actual runtime error and what remains unknown.

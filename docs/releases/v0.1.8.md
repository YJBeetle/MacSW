MacSW 0.1.8（构建 10）

- 新增全局 `sw-cli` 命令安装／卸载入口：在「设置 → 维护 → 命令行工具」选择「安装到 PATH」，随后可直接运行 `sw-cli document inspect --document active --json`。命令链接到当前 App，支持符号链接启动；已有的其他来源同名命令不会被覆盖。
- 内置 SWCLI 升级到已发布的 **0.1.0a13**，包含简单闭合多边形草图支持。
- 在 Wine shell32 创建进程前跳过 Windows 菜单／快捷方式导出，避开保存、打开文档时触发菜单助手的已复现阻塞路径；内部最近文档记录继续保留。
- MacSW 正常退出清理失败时，提供明确的「强制退出」入口。

下载 `MacSW-0.1.8-macOS-signed.zip`，解压后将 MacSW.app 放入「应用程序」。已有版本也可通过「检查更新」升级。安装更新前请保存并退出 SOLIDWORKS。

全局命令是可选安装项，需要时系统会显示管理员授权；终端的 PATH 需包含 `/usr/local/bin`。卸载命令仅移除入口，不删除 App 或容器。移动 App 前，请先卸载命令，再从新位置重新安装。

此版本已通过 Developer ID 签名、Apple 公证、票据附加、轻量可见 SOLIDWORKS 冒烟及 macOS 15 的 x86／x64 新容器初始化验证。隐藏完整 CAD 测试为独立诊断，不是本次发布门禁。新增命令安装入口已通过自动化测试，管理员授权弹窗和设置按钮尚未完成真实用户点击验收。

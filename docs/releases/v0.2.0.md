MacSW 0.2.0（构建 14）

- Wine 升级至 11.21，迁移并保留窗口、输入法、字体、显示器热插拔和并发屏障兼容修复。使用上游 FBO 与窗口截图实现，同时保留 24/32 位位图格式转换，避免 BMP 和 PDF 内嵌图片像素错位。
- 内置 SWCLI 更新至 v0.2.2，命令入口统一为 `swcli`。已安装旧命令的用户可在「设置 → 维护 → 命令行工具」更新全局入口。
- 菜单栏标题旁直接显示 MacSW 软件版本。
- 支持 MCP stdio 接入，工具名为 `status`、`daemon_start`、`daemon_stop`、`capabilities`、`execute`。随包技能和「复制 AI 接入信息」对应的新安装指引保持一致；需要重新加载已安装的旧技能与 MCP 工具清单。
- MCP 渲染结果可直接返回 PNG 预览，导出结果可返回原始文件附件；超过内联上限或附件传递失败会单独标明，不会重复执行已成功的导出。
- 同步新版 CLI 的文档单位和标注选项操作。daemon / SOLIDWORKS 的启动与停止保持显式操作，断开 MCP 不会结束 SW；Wine 下默认不显示 Windows 托盘图标，MacSW 原生菜单栏不变。

本机已验证自定义属性保存重开、原生面板只读打开、中文保存和覆盖、STEP AP214 导出选项、中文输入与空格快捷键、Finder 定位，以及硬件/软件渲染位图和软件渲染 PDF。热插拔后原先的小区域拖动限制未复现；窗口回屏和最大化恢复仍有差异，长期内存趋势尚无结论。

通过 MacSW 的「检查更新」升级，或下载 MacSW-0.2.0-macOS-signed.zip 后替换「应用程序」里的 MacSW.app。请先保存并退出 SOLIDWORKS，更新后按「维护」页提示升级容器。

SHA256SUMS 提供附件校验值，release-info.zip 包含构建来源、签名清单与公证记录。

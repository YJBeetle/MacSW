MacSW 0.1.9（构建 11）

- 修复 Wine 保存 SOLIDWORKS 文件时的 XML 命名空间问题。普通保存和另存后的文件重开时能正常读取自定义属性。
- 修复 macOS 上 Wine 并发执行进程级内存屏障时可能卡住的问题。在实际零件上验证了另存后批量解除压缩的流程。
- Finder 支持 SOLIDWORKS 零件、装配体和工程图的空格静态预览及图标缩略图。没有内嵌预览时显示普通文件图标。
- 内置 SWCLI 更新至 0.1.0a14。「复制 AI 接入信息」现在引导安装可供新对话发现的 MacSW 技能，并说明如何处理 SWCLI 尚未覆盖的 SOLIDWORKS API 操作。

通过 MacSW 的「检查更新」升级，或下载 `MacSW-0.1.9-macOS-signed.zip` 后将 MacSW.app 放入「应用程序」。请先保存并退出 SOLIDWORKS，更新后按「维护」页提示升级容器。

若此前保存的文件重开后属性列表为空，请保留原件。此版本修正新保存的文件，已有文件不会自动重写。

`SHA256SUMS` 提供附件校验值，`release-info.zip` 包含构建来源、签名清单与公证记录。
